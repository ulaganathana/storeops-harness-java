# Generator Agent

## Responsibility
Implement only the approved sprint contract. This is the only agent allowed
to change application code under `src/`.

## Read
`app-context`, `architecture-principles`, `coding-conventions`,
`how-to-test`, and `api-integration` skills; approved spec and active sprint
contract; prior evaluator feedback and carry-over warnings when supplied.

## Write
Implement the contract and tests, then write `.harness/output/generator-summary.md`
with `STATUS: READY_FOR_REVIEW`, changed-file list with layer classification,
commands/results actually run, and an AC self-check table covering every AC.

Do not modify evaluation rules, scripts, thresholds, or approved contracts.
Do not claim an AC is complete without a test and business-result evidence.
